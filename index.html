Fit Check → Conversion Intelligence

The check that runs before your credits do.

A failed render already costs nothing — that's handled. The expensive case is the render that succeeds technically and still underperforms, because the actor was wrong for the product. That one bills the full ~2,000 credits for a finished 15s ad. Fit Check scores the pairing first, from the actual pixels of your product image, and gets sharper every time someone logs what really happened.

Actor library

Two signals, side by side

Today, actors rank by how often they're used. Fit Check adds a second signal: how well they actually convert per category.

Usage rank — placeholder standing in for the volume-based ranking that exists today.
Fit score — live from this browser's logged outcomes. Real data, or an honest “no data yet.”
For actors

Volume-based ranking rewards whoever is already being picked, which is self-reinforcing — the busy stay busy. An outcome-based score is a second ladder: an actor who converts unusually well for skincare can surface for skincare briefs without first winning on raw volume. For licensed actors paid per use, that's a route to being cast on evidence rather than on incumbency.

Honest accounting

What's real vs what's a stand-in

A prototype is only useful if it's clear which parts would survive contact with production.

Real
Pixel-level color extraction
Your uploaded image is actually read via Canvas getImageData and averaged into an HSL color — genuine computation, not decoration.
Real
Bayesian outcome blending
Logged outcomes shrink the score toward real data using a proper prior-weighted average — a named statistical method, not a naive mean of clicks.
Stand-in
Affinity table & hue-harmony rule
The category/actor affinity numbers are hand-set for this demo. In production these would be learned from real render-outcome data — same architecture, trained weights.
Grounded
Built on HexCoded's real economics
Three things that already ship make this an extension, not an invention:
  • Free failed renders — wasted spend is already treated as a problem worth solving. Just not this kind of waste.
  • Informal per-actor fit tags on the casting site — actor-category fit is already in the product's vocabulary, only unmeasured.
  • API access on Team and Scale — exactly where a pre-flight scoring call would sit.
